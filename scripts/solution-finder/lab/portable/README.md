# Solution Finder Lab - standalone copy

Private local QA tool. Share only with authorized coworkers who have access
to the configured company QA tenants. Do not publish this archive publicly.

## Install and start

1. Install **Node.js 22 or 24 LTS**, including npm.
2. Extract the entire ZIP into a writable folder. Do not run inside the ZIP.
3. Open Terminal or PowerShell in the extracted `solution-finder-lab` folder:

   ```text
   npm ci
   npm run setup
   npm start
   ```

4. Open **http://127.0.0.1:4180**.

The setup step installs the Chromium version matching this package.
Linux may need browser system dependencies: `npx playwright install-deps chromium`.
Corporate VPN, QA access, firewall/proxy permissions and an internet connection
for dependency/browser installation may be required.

No full automation repository, TypeScript build, Git, Copilot, mobile tooling,
API credentials or `.env` file is required. The server binds to loopback only;
do not expose it through a network proxy or tunnel.

To select another port:

```text
# PowerShell
$env:SF_LAB_PORT = "4181"
npm start

# macOS/Linux terminal
SF_LAB_PORT=4181 npm start
```

Stop with Ctrl+C. Finish active work before stopping. Interrupted runs are
never automatically retried/resumed.

## Inputs and privacy

This shareable package deliberately contains **no built-in customer/workbook
scenario inputs**, account registry, saved templates/runs, screenshots, auth
state, secrets, `.env`, or original spreadsheets.

Paste your company's approved QA inquiry JSON into the visible JSON box,
validate, edit with the tables and save named templates. Saved templates then
appear in the scenario picker and can be checked for sequential suite runs.
Load or paste **two different requests**, save each under a different name,
then select their checkboxes to run a suite. Never use unapproved real identities.

Each inquiry requires explicit QA authorization and may create QA inquiries
and applications. A fresh QA email is generated by default. It does not create
a funded loan, select an offer or send offers to a borrower.

Five tenant choices, structured editing, pasted JSON, previews, templates,
reset, single runs, sequential suites and separate full-suite results are
included. Retired SSI is Navigator's label and maps to Social Security; the
observed age-62 UI threshold is not federal SSI benefit eligibility.

Saved inputs stay in
`test-data/solution-finder/workbook-scenarios/lab-templates/`.
Execution evidence stays in `test-results/<date>/solution-finder/lab/`.
Both contain local QA data after use. Share the **original clean ZIP**, not
a ZIP of your used working folder. Restrict access to your laptop/folder.

## Troubleshooting and verification limits

- Port in use: stop the other lab or choose another port.
- Missing dependencies/browser: run `npm ci`, then `npm run setup`.
- QA navigation/access failure: check VPN and company QA access; this package
  does not grant permissions or bypass network restrictions.
- Corporate browser-download restrictions: ask your IT team to allow the
  Playwright browser download rather than disabling security checks.
- Workspace empty: expected on a clean install; paste approved input and save
  a template. Saved runs are history, not saved reusable suite definitions.
- The package uses platform-neutral Node/Playwright launch paths and restores
  platform-specific browser binaries during setup. macOS extraction/install/UI
  and runner discovery are verified; Windows/Linux execution is not certified.
